# libGDX 2D Particle Showcase

Interactive 2D procedural particle system built with **libGDX** and **Scene2D**, designed for clean architecture, zero external texture dependencies, and cross-platform execution on **Desktop** and **Android**.

![2D Particle Showcase](docs/particle-showcase.gif)

## Features & Technical Highlights

- **Procedural Rendering:** Real-time particle emitters and visual feedback rendered cleanly with `ShapeRenderer` and Scene2D UI/controls.
- **Interactive Controls:** Responds to pointer/touch input and on-screen controls across desktop and mobile viewports.
- **Cross-Platform Ready:** Built to run consistently on both Desktop and Android targets.

## Running the Project

1. Clone the repository and open the Gradle project in your IDE (IntelliJ IDEA or Android Studio).
2. Run the **Desktop** launcher for mouse/keyboard testing, or deploy to an **Android** device/emulator to test touch controls.
